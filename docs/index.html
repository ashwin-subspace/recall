Recall

A tutor that remembers you.

Recall keeps a local model of what you have studied: which concepts you have hit, how solid each one is, and the specific misunderstandings you have shown. A session opens on the thing that is due. The tutor speaks first. Ending the session writes the result back into SQLite on the phone.

Java, Android, SQLite, Gemini or Groq. No server and no account.

The API key is yours. Paste a free Gemini or Groq key in the app. It stays on the device and is sent only to the provider you pick. It is not in the source, the APK, or this page.

Download APK

bash build.sh writes Recall.apk locally. The download above is the signed release asset.

What it does

  1. Home names one target from the model on the phone.
  2. Session opens with the tutor, then you answer. Voice uses the system recognizer.
  3. End asks the model for a structured update and folds it into SQLite. If that call fails, the transcript can still be kept.
  4. Mind and Progress show the model back to you: confidence, gaps, and whether a line is even worth drawing yet.

Build

JDK 21 (JAVA_HOME, with javac and jar) and an Android SDK (ANDROID_HOME) with build-tools 36.0.0 and platforms/android-36. A debug keystore at ~/.android/debug.keystore signs the APK.

bash build.sh

The live tutoring round-trip has not been verified. A rejected key is how the app shows that the phone reached Gemini or Groq. Paste your own key on the device and use Test connection.
